The map is plain files, ranked by one deterministic function

Facts, workstreams, decisions and catalogs are Markdown/YAML. Search is brain.py's ranking: stemmed prefix matching, rarer words weigh more, title/tags count extra. Edit a file and search again; every other tab uses your edited copy.

Break the brain, see which evals notice

A mutation is a deliberate, wrong edit to the knowledge. If no eval fails, the evals have a blind spot. This is the idea behind mutation_check.py, reimplemented over the real eval code.

The deterministic gate: same results in, same verdict out

A model produces noisy per-sample outcomes once (a fixture here, hand-set by you). gate.decide then turns them into ADOPT / NO_DELTA / CEILING / REGRESSION / TOO_COSTLY. Click cells to flip individual outcomes; change thresholds; the verdict is recomputed by the real function.
