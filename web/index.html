Your agent passes the demo. How do you know it's good?

Guardrails limit what an agent may do. Observability shows what it did. Evals measure how well it does. This site is about evals: you predict what the real code will do, then watch it run.

  1. How do you check an agent's answer?An eval is a question plus a pass/fail check. See what the check really looks at.
  2. Can you trust the check?A passing suite can still be blind. Break things on purpose and see what notices.
  3. Can you trust one run?One run is not evidence. A gate turns results into a verdict you can defend.
  4. Can you see what happened?A score says how often. A trace says what happened in each answer.
  5. Can you limit what it does and says?A guardrail decides what an agent may do or say. Test it like anything else.
